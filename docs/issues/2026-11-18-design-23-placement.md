# design_23만 배치 예측이 20 Å 어긋난다

- 발견: 2026-11-18 (교정 실행)
- 상태: **원인 미규명.** 입력 결함은 배제됨
- 영향: `Trka_binder_design_23` 한 건. 다른 19개 설계는 정상

## 증상

실험에서 결합이 확인된 설계인데 이번 예측만 결합여가 표적에서 20.30 Å 떨어진 곳에 놓였다.
저자들의 공개 AF2 구조와도 20.77 Å 차이다. 같은 실행의 나머지 19개는 공개 AF2를
0.157 ~ 1.942 Å로 재현했다.

| 지표 | design_23 | 같은 실행의 나머지 19개 |
| --- | --- | --- |
| 배치 RMSD (`target_aligned_rmsd`) | **20.298 Å** | 0.798 ~ 3.942 Å |
| 공개 AF2와의 차이 | **20.772 Å** | 0.157 ~ 1.942 Å |
| `pae_interaction` | **26.392** | 4.392 ~ 8.796 |
| 접힘 (`binder_aligned_rmsd`) | 0.580 Å | 0.398 ~ 0.889 Å |

**접힘은 정확하고 배치만 어긋났다.** 이는 표적 사이드체인 누락 때문에 발생했던
[원래 TrkA_88 실패](2026-11-18-trka-target-sidechains.md)와 같은 양상이다.

## 배제된 원인

성공한 design_88과 동일한 기준으로 준비된 복합체를 점검했고 차이가 없었다.

| 점검 | design_23 | design_88 (성공) |
| --- | --- | --- |
| 사슬 구성 | A 94잔기 / B 101잔기 | A 93잔기 / B 101잔기 |
| 표적 서열이 기준과 일치 | 예 | 예 |
| 결합여 내부 주사슬 끊김 | 없음 | 없음 |
| 계면 최단 중원자 거리 | 2.21 Å | 1.96 Å |
| 계면 접촉 (< 4 Å) | 48쌍 | 52쌍 |
| 표적 사이드체인 | 이식됨 | 이식됨 |

따라서 표적 사이드체인 문제의 재발이 아니고, 사슬 구성이나 서열 준비 오류도 아니다.
준비 단계 실패 기록(`prepare_failures.json`)도 비어 있다.

## 다음에 할 일

TrkA_88에 적용했던 [진단 절차](../../diagnostics/README.md)를 design_23에 그대로 돌린다.
시드 변경, recycle 증가, `initial_guess` 해제, 공개 AF2 좌표 투입 대조군, 입력 특징
배열 비교까지. AF2 10여 회, 약 20분이면 된다.

특히 확인할 것:

- 공개 AF2 좌표를 투입하면 통과하는가. 통과하면 입력 좌표 문제, 아니면 모델 쪽 문제다.
- 시드를 바꾸면 결과가 바뀌는가. 바뀌면 단순히 이 설계에서 탐색이 실패한 것이다.
- 저자들이 이 설계에만 다른 조건(`Noise_level`, `Fold_conditioned`, `Monomeric`)을
  썼는지. 값은 `calibration.csv`에 함께 기록돼 있다.

## 이 건이 교정 결과에 미치는 영향

결론은 바뀌지 않는다. 교정의 핵심은 **비결합체 14개가 전부 통과했다**는 쪽이고,
design_23을 결합체 통과 집계에서 빼더라도 "지표가 두 그룹을 가르지 못한다"는 결과는
그대로다. 다만 결합체 통과율을 5/6으로 보고할 때 이 건이 재현 실패일 가능성을 함께
적는다. [교정 결과](../02-filter-calibration.md)
