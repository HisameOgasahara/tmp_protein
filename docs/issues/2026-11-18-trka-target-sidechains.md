# 공개 design.pdb에 표적 사이드체인이 없어 AF2 재현이 실패

- 발견: 2026-11-18
- 상태: **해결.** 수정 후 재현 성공 (1.496 Å, `pae_interaction` 5.86)
- 영향: TrkA_88 재현 실행 전부, 그리고 같은 입력을 쓰는 모든 공개 설계

## 결론 먼저

표적 사이드체인을 실험 구조에서 이식하자 재현이 성공했다.

| 지표 | 수정 전 | 수정 후 | 논문·공개 자료 |
| --- | --- | --- | --- |
| 표적 기준 결합체 RMSD | 32.780 Å | **1.496 Å** | 논문 1.4 Å, 공개 AF2 재계산 1.390 Å |
| 공개 AF2 구조와의 차이 | 32.157 Å | **0.191 Å** | — |
| `pae_interaction` | 26.15 | **5.86** | 통과선 < 10 |
| `plddt_binder` | 94.36 | 93.30 | 통과선 > 80 |

업스트림 코드가 자체 산출한 `target_aligned_rmsd`도 1.497 Å로 일치한다.
실행 기록: [results/2026-11-18-trka88-diagnostics-v2](../../results/2026-11-18-trka88-diagnostics-v2)

## 증상

실험으로 결합이 확인된 공개 설계 TrkA_88을 업스트림 AF2 코드로 재예측하면 결합체가
표적에서 **31.14 Å 떨어진 위치**로 예측된다. 논문 보고값은 약 1.4 Å이다.

| 지표 | 재현 실행 | 기대값 |
| --- | --- | --- |
| 표적 기준 결합체 RMSD | 31.14 Å | ~1.4 Å |
| `pae_interaction` | 26.07 | < 10 |
| `plddt_total` | 94.42 | 높음 (정상) |
| `binder_aligned_rmsd` | 0.594 Å | 작음 (정상) |

pLDDT가 94로 높고 결합체 자체 접힘도 0.594 Å로 정확하다. **접힘은 맞고 배치만 틀렸다.**

## 원인

공개 `design.pdb`는 **주사슬 원자(N, CA, C, O)만** 담고 있다. 결합체 93잔기는 전부 GLY
플레이스홀더이고, 표적 101잔기는 잔기 이름은 올바르지만 사이드체인 원자가 없다.

PyRosetta로 이 파일을 읽으면 없는 사이드체인을 기본 로터머로 생성한다. 그 결과:

| 비교 (공개 AF2 표적 기준) | 값 |
| --- | --- |
| 표적 주사슬 RMSD | 0.355 Å (정상) |
| 표적 사이드체인 RMSD | 1.634 Å, 최대 8.339 Å |
| 사이드체인 원자 중 2 Å 초과 편차 비율 | 16% |

업스트림 `af2_util.af2_get_atom_positions`는 입력 PDB의 **모든 원자**를 표적 템플릿과
초기 좌표에 넣는다. 지어낸 사이드체인이 여과 없이 AF2에 전달된다.

결합면에 실제 충돌이 생긴다.

| 복합체 | 사슬 간 중원자 2.5 Å 미만 쌍 | 최소 거리 |
| --- | --- | --- |
| 준비된 입력 (사이드체인 재구성) | 5쌍 | 2.06 Å (Tyr63 CD1 – Met108 CE) |
| 공개 AF2 구조 | 1쌍 | 2.29 Å |

AF2는 이 충돌하는 결합면을 거부하고 결합체를 떼어낸다.

## 원인 확정 근거

[진단 실험](../../diagnostics/README.md)에서 11개 조건을 비교했다.

설계 좌표에서 출발하는 9개 조건은 모두 실패했다 — 시드 0/1/2, recycle 3/12,
JAX 정밀도 default/highest, 서열 입히기 방식 2종, `initial_guess` 해제, 표적 템플릿 비우기.
결과 범위 **24.19 ~ 48.83 Å**, `pae_interaction` 25.57 ~ 26.51. 같은 시드에서는
32.780 Å이 그대로 재현되어 비결정성 문제도 아니다.

표적 좌표만 바꾼 두 조건은 통과했다.

| 조건 | 설계 기준 RMSD | 공개 AF2 기준 RMSD | `pae_interaction` |
| --- | --- | --- | --- |
| `original_thread` (실패 기준) | 32.780 Å | 32.157 Å | 26.15 |
| `published_coordinates_control` | 1.648 Å | 0.409 Å | 4.86 |
| `published_target_control` | 1.654 Å | 0.412 Å | 4.86 |

`published_target_control`은 공개 AF2의 **표적 원자만** 설계 좌표계에 정렬해 넣고 결합체는
설계 좌표를 그대로 쓴 조건이다. 입력 특징 배열을 직접 비교한 결과
(`feature_differences.json`), 실패 조건과의 차이는 **표적 템플릿 좌표와 초기 좌표뿐**이고
(최대 6.674 Å) 잔기 94–193, 즉 표적 구간에만 있었다. 결합체 구간 차이는 정확히 0이었다.

즉 표적의 전체 원자 좌표 하나만 바꿔서 31 Å 실패가 1.65 Å 성공으로 바뀐다.

## 대처법

### 적용한 것 — 실험 구조에서 사이드체인 이식

저자들이 쓴 표적 입력 대신 실험 구조를 썼다. figshare 아카이브
(`RFdiffusion_designs.zip`, 251.7 MB)는 받을 수 있지만 당시에는 HEAD 요청이 403을
돌려줘 막힌 것으로 판단했다. 실제로는 GET으로 받을 수 있다.

**PDB 1WWW 체인 X의 TrkA Ig 유사 D5 도메인(잔기 282–382) 서열이 `design.pdb` 표적
101잔기와 글자 하나까지 동일하다.** 정렬 모호성이 없어 잔기별 대응이 확정된다.

구현은 [src/af2_filter/target_sidechains.py](../../src/af2_filter/target_sidechains.py)다.
각 잔기의 N/CA/C 국소 좌표계로 중첩한 뒤 사이드체인 원자만 옮긴다. 전역 중첩이 아니라
잔기별로 하는 이유는 두 구조의 주사슬이 최대 1.6 Å 어긋나 있어 전역 변환으로는
사이드체인이 제자리에 놓이지 않기 때문이다.

검증 결과:

| 항목 | 값 |
| --- | --- |
| 설계 주사슬 보존 (양 사슬 776원자) | 최대 편차 **0.000000 Å** |
| 추가된 표적 사이드체인 중원자 | 0개 → **378개** (공개 AF2 구조는 379개) |
| 사이드체인 없는 표적 잔기 | 없음 |
| 공개 AF2 표적과의 사이드체인 RMSD | **1.296 Å** (PyRosetta 재구성본은 1.601 Å) |
| 2 Å 초과 편차 비율 | **14%** (재구성본은 20%) |

이식한 사이드체인은 공개 AF2 표적과 RMSD 1.296 Å 차이였다(재구성본 1.601 Å). 이 차이가
AF2에게 충분히 가까운지는 실행으로만 판정되는 문제였고, 진단 조건
`grafted_target_sidechains`로 알려진 정답 대조군 두 개와 나란히 비교했다.
[진단 문서](../../diagnostics/README.md)

**충분히 가까웠다.** 1.496 Å / `pae_interaction` 5.86으로 통과했다. 공개 AF2 구조와는
0.191 Å 차이로, 정답 좌표를 직접 투입한 대조군(0.409·0.412 Å)보다 오히려 가깝다.
대조군은 AF2 자신의 예측을 되먹인 것이고 이쪽은 독립적인 결정 구조를 쓴 결과다.

표적은 95개 공개 설계 전체가 공유하므로 **한 번 복원하면 전부에 적용된다.**

## 사이드체인이 원인임이 확정됨

이전에는 `published_target_control`이 표적 사이드체인과 주사슬(0.355 Å)을 동시에 바꿨기
때문에 "사이드체인만이 원인"으로 좁혀지지 않았다. 이식 조건이 그것을 해결했다.

입력 특징 배열을 실패 기준(`original_thread`)과 비교한 결과:

| 바뀐 특징 | 이식 조건 | `published_target_control` |
| --- | --- | --- |
| `template_all_atom_positions` 최대 차이 | 5.354 Å | 6.674 Å |
| `template_pseudo_beta` 최대 차이 | **0.202 Å** | 1.425 Å |
| `initial_guess/coordinates` 최대 차이 | 5.354 Å | 6.674 Å |
| 결합체 구간 차이 | 0 | 0 |

`template_pseudo_beta`는 CB(글리신은 CA) 위치다. 이식 조건에서는 그 값이 **0.202 Å밖에
바뀌지 않았다.** 설계 주사슬은 편차 0.000000 Å로 그대로이고 CB도 사실상 제자리인데,
**CB 바깥 사이드체인 원자만 바뀌어서 32.780 Å이 1.496 Å이 됐다.**

따라서 원인은 주사슬이나 CB 배치가 아니라 **CB 바깥 사이드체인 좌표**로 확정된다.
AF2의 표적 템플릿과 초기 좌표가 그 원자들을 그대로 받기 때문이다.

## 남은 불확실성

- 이식에 쓴 1WWW는 결정 구조이고, 저자들이 RFdiffusion 입력으로 실제 쓴 표적 파일과
  같은지는 확인하지 않았다. figshare 아카이브에서 꺼내 비교할 수 있다. 다만 공개 AF2
  결과를 0.191 Å로 재현했으므로 실용적으로는 충분하다.
- 95개 설계 중 재현을 확인한 것은 TrkA_88 한 건이다. 나머지 설계에서도 같은 수정으로
  통과하는지는 구조 파일을 추가로 받아 확인해야 한다.

## 재발 방지

[src/af2_filter/predict.py](../../src/af2_filter/predict.py)에 단정을 추가했다. AF2에
넘기기 직전의 복합체에서 GLY가 아닌 표적 잔기가 사이드체인 원자를 하나도 갖지 않으면
실행을 중단하고 해당 잔기 번호를 보고한다.

이전에는 서열·사슬 경계·주사슬 좌표만 검사했기 때문에, 사이드체인이 통째로 비어 있어도
파이프라인이 끝까지 정상 종료하고 틀린 숫자를 냈다. **조용히 틀리는 것이 이 문제의
본질이었다.** [설계문서의 검증 지점](../01-pipeline.md) 참조.
