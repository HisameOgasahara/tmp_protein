## 과거 실험에서 확인됐으나 이 저장소 범위를 벗어난 기록

아래는 GFP 표적으로 진행했다가 중단한 실험에서 나온 결과다. 코드와 결과는 git 이력의
`archive/2026-11-18-pre-restructure` 태그 이전 커밋에 남아 있다. 재현 가능한 형태로
정리되지 않았으므로 현재 결론에 포함하지 않지만, 기록 가치가 있는 관찰은 다음 두 개다.

- **서열만 주는 복합체 예측은 결합 자세를 찾지 못했다.** 두 사슬의 구조를 모두 템플릿으로
  주면 알려진 복합체를 재현했고(3/3, 결합체 RMSD 0.70–0.87 Å), 결합체 템플릿을 제거하면
  실패했다(0/3). 이 관찰이 현재 설계문서가 AF2 initial guess를 채점기로 고정한 이유다.
- **강체 도킹이 구조 예측보다 자세를 잘 찾은 사례가 있었다.** 구조 예측이 10개 시드에서
  못 찾은 자세를 MEGADOCK이 수 초 만에 0.99 Å로 찾았다. 다만 점수 1위 후보는 중원자
  최소 거리 1.265 Å의 충돌이 있는 오답이었고, 충돌 필터를 넣어야 정답이 1위가 됐다.
  충돌 허용 거리를 2.05 Å로 올리면 정답이 탈락하므로 거리 기준은 민감하다.
