## 소요 시간 분해

규모를 키우기 전 로그의 설계별 AF2 시간을 집계.

| 항목 | 시간 | 비중 |
| --- | --- | --- |
| **JAX 재컴파일** — 길이 17종 × 92.0초 | 1564초 | **62%** |
| AF2 추론 — 41회 × 10.5초 | 430초 | 17% |
| 특징 생성·채점·출력 — 41회 × 9.4초 | 387초 | 15% |

처음 보는 총 길이 17회 평균 102.5초, 같은 길이 재사용 24회 평균 10.5초. 차이 92.0초가
컴파일 비용. 같은 길이의 두 번째 실행에서 98.9초 → 10.2초로 떨어짐(design_11_seq01 →
design_13_seq02, 둘 다 총 181잔기).

원인은 contig `70-95`. JAX는 입력 모양이 바뀌면 커널을 다시 컴파일하는데 백본 20개에서
길이 17종이 나옴. 컴파일 횟수는 실행 순서와 무관 — JAX가 모양별 결과를 전부 캐시.

**선택: contig 첫 필드를 단일 값으로 고정.** 설계 수와 무관하게 컴파일은 길이 종류 수만큼.

| 길이 4종, 40개 | 15.5분 | 23초 |
