# 경과 — 각 실행이 다음 결정을 바꾼 과정

처음 목표는 설계 파이프라인을 끝까지 돌려보는 것. 현재 형태는 매 실행의 결과가 다음
결정을 강제한 결과. 숫자와 근거는 링크한 문서에.

| # | 실행 | 결과 | 다음 결정 |
| --- | --- | --- | --- |
| 1 | 표적 없는 단량체 설계·역검증 | 16/20이 Cα RMSD < 2 Å | 표적을 붙이기로 |
| 2 | PD-L1 표적 설계 | 설계는 작동, 채점 방법이 부적절 | 채점기를 먼저 고정 |
| 3 | 표적 전환 | TrkA — 공개 설계 + 실험 라벨 | 재현을 1차 목표로 |
| 4 | TrkA_88 재현 시도 | 두 경로 모두 실패, 양상 동일 | 설정 탐색 중단, 통제 실험으로 |
| 5 | 12조건 통제 실험 | 표적 좌표만이 결과를 바꿈 | 원인 후보를 하나로 |
| 6 | 사이드체인 이식 | **1.496 Å, `pae` 5.86** | 재현 성공 |
| 7 | 라벨된 설계 20개 교정 | 비결합 14/14 통과 | 통과 집합 내 순위를 매기지 않기로 |
| 8 | 교정 집합의 성질 확인 | 이미 선별을 통과한 집합 | 날것을 측정하기로 |
| 9 | 직접 설계 40개 | **0/40**, 대조군은 통과 | 시간 분해 후 규모 확대 |
| 10 | 소요 시간 분해 | 채점의 62%가 재컴파일 | 길이 고정 |
| 11 | 설계 160개 | **0/160**, `pae` 최소 8.480 | 서열 8개 유지, 사전 필터 안 폐기 |
| 12 | 백본 1개 × 서열 50 | **1/50 통과** | 한계 지점은 서열 추출 수 |

## 1. 단량체 자기일관성

표적 없이 80잔기 단량체 생성 → 서열 설계 → 역검증. 20개 중 16개가 Cα RMSD < 2 Å,
최소 0.512 Å.

파이프라인은 끝까지 작동. 확인된 것은 자기일관성뿐이고 표적이 없어 결합과 무관.

→ [results/2026-11-16-monomer-selfconsistency](../results/2026-11-16-monomer-selfconsistency)

## 2. 채점 방법 문제

RFdiffusion3 공식 예제 PD-L1(8AOM)로 백본 8개, 서열 16개 생성. 설계 단계는 정상.
채점은 RF3에 서열만 넘기고 표적 템플릿·초기 좌표를 주지 않음. 자세 RMSD 8.9–31.1 Å이
나왔으나 설계 품질과 채점 부적절을 구분할 수 없음.

**채점 방법을 먼저 고정하지 않으면 결과를 해석할 수 없음** — 현재 설계문서의 전제.
이 실행의 숫자는 결론에 쓰지 않음.

→ [results/2026-11-18-pdl1-8aom-rf3](../results/2026-11-18-pdl1-8aom-rf3) ·
[01-pipeline](01-pipeline.md)

## 3. 표적 전환

채점기 교정에는 정답이 있는 사례가 필요. TrkA는 공개 자료에 설계 구조·설계 서열·저자의
AF2 예측 구조·실험 결합 라벨이 모두 있음.

목표가 "새 설계 생성"에서 "알려진 결합체의 공개 결과 재현"으로 변경.

→ [00-purpose](00-purpose.md) · [references](references.md)

## 4. 재현 실패

TrkA_88을 두 경로로 실행. ColabDesign 38.66 Å, 업스트림 `predict.py` 31.14 Å. 논문 1.4 Å.
두 경로의 실패 양상이 동일 → 구현 실수가 아니라 공통 입력의 문제.

설정 변경 탐색을 중단하고 조건 통제 실험으로 전환.

→ [results/2026-11-18-trka88-af2-upstream](../results/2026-11-18-trka88-af2-upstream)

## 5. 통제 실험

시드·recycle 수·수치 정밀도·입력 구성 등 12조건을 하나씩 변경. 탐색 설정은 전부 무관,
표적 좌표만이 결과를 변경. AF2에 들어간 배열을 가로채 저장해 비교.

→ [diagnostics](../diagnostics/README.md) ·
[results/2026-11-18-trka88-diagnostics](../results/2026-11-18-trka88-diagnostics)

## 6. 원인과 수정

공개 `design.pdb`는 주사슬 전용(N, CA, C, O). PyRosetta가 표적 사이드체인을 기본
로터머로 재구성했고, 그 원자들이 AF2의 표적 템플릿과 초기 좌표로 들어가 충돌하는 결합면을
구성.

결정 구조 PDB 1WWW 체인 X에서 사이드체인을 잔기별로 이식. 설계 주사슬 편차 0.000000 Å.

| | 수정 전 | 수정 후 |
| --- | --- | --- |
| 배치 RMSD | 31.14 Å | **1.496 Å** |
| `pae_interaction` | 26.07 | **5.86** |

공개 AF2 구조와 0.191 Å 차이 — 정답 좌표를 직접 투입한 대조군(0.409·0.412 Å)보다 가까움.
실패한 실행에서도 결합체 자체 접힘은 0.594 Å로 정확하고 배치만 어긋났음.

→ [문제 기록](issues/2026-11-18-trka-target-sidechains.md) ·

[results/2026-11-18-trka88-diagnostics-v2](../results/2026-11-18-trka88-diagnostics-v2)

## 7. 지표 교정

결합체 6개 전수와 비결합체 14개를 같은 필터로 채점. 비결합체 14/14 통과, 결합체 5/6 통과.
최저 점수 4.39의 주인이 비결합체.

통과 후 실제 결합률 6/95 = 6.3%. 통과 집합 안에서 `pae_interaction` 순위를 쓰지 않기로.

부수 확인 — 20개 중 19개가 저자들의 AF2 구조를 0.157–1.942 Å로 재현.

→ [02-filter-calibration](02-filter-calibration.md) ·
[results/2026-11-18-trka88-calibration](../results/2026-11-18-trka88-calibration)

## 8. 교정 집합의 성질

95개는 저자들이 이미 계산 필터를 통과시켜 실험에 보낸 설계. 걸러진 집합 안에서 같은
필터를 다시 적용하면 변별력이 남지 않음.

7번이 측정한 것은 선별 후 집단. 선별 전 집단에 대한 효과는 미측정 → 날것을 직접 설계해
측정하기로.

→ [02-filter-calibration](02-filter-calibration.md)

## 9. 직접 설계 40개

같은 표적에 백본 20개, 서열 40개. 공개 결합체 TrkA_88을 양성 대조군으로 같은 배치에 포함.

0/40 통과, 대조군 `pae_interaction` 5.862 통과. 7번과 합치면 — 필터는 선별 전 집단에서
거르고 선별 후 집단에서는 가르지 못함.

탈락은 계면 항 하나. `plddt_binder` 32/40, 접힘 21/40, `pae_interaction` 0/40.

채점 전 설계 단계 검증 — 백본 20개 전부가 Met108·Leu145에 접촉.

→ [03-design-run](03-design-run.md) ·
[results/2026-11-19-trka-design](../results/2026-11-19-trka-design)

## 10. 시간 분해

0/40에서 참 통과율의 95% 상한은 7.22%로 범위가 넓어 규모 확대가 필요. 소요 시간을 먼저
분해한 결과 채점 2531초 중 1564초(62%)가 JAX 재컴파일. 길이당 92초, 실제 추론 10.5초.

길이를 4종으로 고정해 컴파일을 17회 → 4회로 축소, 그 예산으로 설계를 160개로 확대.

→ [03-design-run](03-design-run.md)

## 11. 설계 160개

컴파일 17회 → 4회, 비중 62% → 9.2%. 설계당 채점 61.7초 → 25.5초. 벽시계 1.7배에 설계 4배.

결과 0/160. 달라진 점:

- `pae_interaction`이 처음으로 통과선 아래 — 8.480. 접힘 1.121 Å로 0.121 Å 부족해 탈락.
- 9번 문서의 "접힘 < 1 Å인 21개 전부가 배치 5 Å 이상 어긋남"은 표본 크기 문제였음.
  160개에서는 둘 다 만족하는 설계가 9개.
- 백본별로 가르면 쓸 만한 값이 백본 3개에서만 발생. 여기서 서열 축소를 제안했다가,
  백본당 첫 서열만으로 선별한 경우를 역산한 뒤 철회. 백본 20개의 `seq01`이 예외 없이
  평탄면이고 최저값 두 개가 서열 8개 중 하나에서만 나옴.
- AF2 앞 값싼 필터는 보유한 백본 40개로 GPU 없이 검증. 기하 설명자 8종 전부 상관이
  0 근처 → 안 폐기.

→ [04-scale-run](04-scale-run.md) ·
[results/2026-11-19-trka-design-v2](../results/2026-11-19-trka-design-v2)

## 12. 백본 1개 × 서열 50

`design_04`가 배치 1.190 Å에 `pae_interaction` 12.934. 백본의 한계인지 서열 추출 수의
문제인지 서열 8개로는 구분 불가 → 같은 백본에 서열 50개 재추출. 백본 생성을 건너뛰어
34분.

`design_04_r22`가 세 기준 전부 통과 — `pae_interaction` 9.389, `plddt_binder` 89.58,
접힘 0.702 Å.

한계 지점은 서열 추출 수. 이 백본은 50개 중 27개가 `pae` 20 아래(넓은 실행은 160개 중
10개), 통과율 2%에서 8개를 뽑아 못 건질 확률 85%. 11번에서 철회한 판단과 같은 지점.

→ [05-focus-run](05-focus-run.md) ·
[results/2026-11-19-design04-focus](../results/2026-11-19-design04-focus)

고정 리비전을 그대로 실행한다는 재현 근거를 깸. 상세는
