## v0.1.9 판정과 예측 조건

모든 조건을 만족하는 자세를 기준 구조 회복으로 판정한다.

| 지표 | 조건 |
| --- | --- |
| GFP Cα RMSD | ≤ 3 Å |
| GFP 정렬 후 결합체 Cα RMSD | ≤ 5 Å |
| 결합체 자체 정렬 Cα RMSD | ≤ 2 Å |
| GFP 접촉면 Jaccard | ≥ 0.5 |
| 기준 잔기 쌍 접촉 회복률 | ≥ 0.5 |
| 충돌 | 없음 |

추가 임계값은 이번 구현에서 선택한 프로젝트 대조군 판정 조건이다. 각 실패 사유와 실제 임계값을 결과에 기록한다. 기준 구조가 있는 대조군의 구조 회복 평가에 적용한다.

Enhancer 단독 접힘에는 나노바디 전용 NanoBodyBuilder2를 적용한다. 서열만으로 예측한 앙상블을 모델 내부 오차 추정으로 정렬하고 구조 보정을 수행한다. 원래 Enhancer 결정 구조는 평가와 대조 조건에 사용한다. 같은 단독 예측 구조를 RF3의 세 시드에 전달해 상대 배치 변화를 비교한다. [ImmuneBuilder 공식 구현](https://github.com/oxpig/ImmuneBuilder)

저장된 도킹 구조 100개를 새 기준으로 재평가하면 2위만 통과한다. 기존 Enhancer 예측 구조 조건은 0/3, 결정 구조 조건은 3/3이다. 결측·비유한 지표의 탈락과 서열 좌표 대응을 포함한 회귀 검사 4개가 통과했다.

새 예측 경로의 실제 Colab 접힘 정확도와 실행 시간은 후속 실행으로 확인해야 한다.
