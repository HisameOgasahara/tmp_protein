## [A1] RF3의 GFP 구조와 결합 자세

같은 GFP 잔기의 Cα를 정렬하고 후보와 지정 잔기 간 Cα 거리가 8Å 이하인 경우를 접촉으로 집계했다. 지정 잔기는 3G9A GFP 체인의 182, 180, 164번이다.

| 비교 대상 | 측정 결과 |
| --- | --- |
| RFD3의 GFP와 입력 결정 구조 | Cα RMSD 0.00Å |
| RF3 후보 복합체의 GFP와 결정 구조 | Cα RMSD 15.4–20.2Å |
| RF3 대조군 복합체의 GFP와 결정 구조 | Cα RMSD 19.3Å, 20.0Å |
| 후보만 따로 정렬한 RF3와 RFD3의 뼈대 | Cα RMSD 0.5–1.8Å |

[`predict_complexes()`](../gfp_pipeline/stages.py)는 GFP와 후보의 서열만 RF3에 전달했다. 따라서 RFD3가 사용한 GFP 결정 구조의 기하 정보가 복합체 예측에서 빠졌다. 후보 자체의 뼈대는 대체로 재현됐지만 GFP 구조와 상대 배치는 크게 달랐다. 실험상 결합하는 대조군에서도 GFP 재현에 실패했으므로 이 실행의 점수로 새 후보의 실제 결합 여부를 판정하기 어렵다.

수정 계획은 GFP 체인만 결정 구조 템플릿으로 전달하고, 대조군에서 GFP 구조와 각자의 결정 구조 접촉면을 함께 평가하는 것이다. 후보의 결합 자세는 RF3가 예측한다. [고정 버전 RF3의 구조 템플릿](https://raw.githubusercontent.com/RosettaCommons/foundry/0d0b0ba44fab7ca76aa4b625c014ce5964c7d284/models/rf3/README.md)

## [A2] 릿지 회귀의 형광 배율 외삽

[`predict_fluorescence()`](../gfp_pipeline/stages.py)는 세 가지 접촉 특징을 `StandardScaler`로 표준화해 형광 배율의 로그₂ 값을 학습했다. 대조군의 결합체 접촉 비율은 32.48%와 32.33%였다. 후보 `backbone_01_seq02`의 16.36%는 두 대조군 기준으로 약 −217 표준편차였다. 이 특징 하나가 로그₂ 예측에 −134를 더했고, 배율로 환산한 최종값은 약 6.69 × 10⁻³⁹이었다.

수정 계획은 복합체 검증 실패, 독립 실험 그룹 부족, 기준 모델 대비 성능 미달, 학습 범위 밖 입력에서 형광 배율을 보류하는 것이다. 기준 모델은 항상 형광 변화 없음인 1배를 출력한다.
