이 대조군에서는 단독 접힘 단계가 주된 실패 지점으로 좁혀진다. RF3 단독 예측 내부의 학습 데이터·입력 특징 중 어떤 요소가 실패를 일으켰는지는 현재 출력으로 분리되지 않는다. NanoBodyBuilder2의 다른 서열에 대한 일반화 성능도 이번 단일 대조군에서 확정할 수 없다.

1위의 가장 가까운 원자 쌍은 저장된 PDB 번호로 GFP 체인 A의 LEU 221 CD2와 결합체 체인 B의 THR 59 N이다. 1.5 Å 미만 쌍도 하나 존재한다. 1위의 점수 우위는 147.82, 2위 대비 약 3.70%이다. [100개 구조의 원자 거리 재계산](../results/07_gfp_diagnostics_1wx_7cqz/minimizer_docking/metrics/clash_analysis.csv)

MEGADOCK은 점수순 후보를 생성하고, 현재 연결 코드는 그 순서로 구조와 지표를 저장한다. 충돌 판정은 후보 생성 뒤에 추가되며 표시 순서에 반영되지 않는다. 따라서 잘못된 1위가 계속 맨 위에 보이는 직접 원인은 충돌 필터를 통과한 후보의 선택 순서가 구현되지 않은 데 있다. [현재 실행 경로](../gfp_pipeline/megadock_compare.py)

상위 100개 중 기존 2 Å 충돌 기준을 통과하는 후보는 27개다. 이 27개를 기존 점수순으로 읽으면 원래 2위가 첫 후보가 된다. 이 선택 계산에는 결정 구조·RMSD·참조 접촉 정보를 사용하지 않았다. 이후 기준 구조와 비교해 RMSD 0.989 Å임을 확인했다.

실행 06과 07에서 저장된 2,000개 후보의 회전·이동 값과 순서는 모두 같았다. 점수 차이는 최대 0.02였다. 이번 강화된 판정은 후보 생성 결과를 바꾸지 않고 기존 31위의 오판정을 제거했다.

## 점수 역전의 미확인 원인

사용한 설정은 격자 간격 1.2 Å와 점수 함수 3이다. MEGADOCK 공식 구현의 상세 출력은 rPSC·정전기·ACE 기여를 구분한다. 이번 실행 명령에는 상세 출력 옵션 `-O`가 없고, ZIP에는 합계 점수만 저장되어 있다. 각 항이 1위에 얼마나 유리했는지와 격자 해상도가 역전에 기여했는지는 현재 자료로 확정할 수 없다. [고정 버전의 상세 점수 구현](https://github.com/akiyamalab/MEGADOCK/blob/87c8432494e0b05daaa17f191c15a56a6840a42d/src/docking.cpp)

다음 원인 분리 실험은 동일 입력·회전 샘플로 상세 점수를 저장해 1위와 2위의 항별 기여를 비교하는 것이다. 격자 간격 비교는 그와 별도로 수행해야 각 변화의 효과를 구별할 수 있다. 현재 분석에서는 기존 후보에 대한 충돌 필터만으로 첫 후보가 개선되는 것까지 확인했다.

## 조치 순서와 확인 기준

| 순서 | 조치 | 확인 기준 |
| --- | --- | --- |
| 1 | 평가한 후보에서 기존 2 Å 충돌 기준을 통과한 후보만 선택 대상으로 삼고 원래 점수순으로 정렬 | 실행 07에서 원래 2위가 선택되는지 확인 |
| 2 | 원래 점수 순위, 충돌 필터 후 순위, 제외 사유, 최종 선택을 각각 기록 | 정답 구조 없이 선택 가능하며 후보가 모두 제외되면 선택 없음으로 표시 |
| 3 | 같은 Minimizer 입력과 3,600개 회전·1.2 Å 격자를 유지하고 MEGADOCK 상세 출력 `-O` 추가 | 1위와 2위의 rPSC·정전기·ACE 기여 차이 확인 |
| 4 | Enhancer의 NanoBodyBuilder2 예측 구조와 GFP로 같은 도킹·선택 절차 실행 | 선택을 완료한 뒤 결정 구조로 RMSD·접촉 회복·충돌 평가 |
| 5 | 위 결과에서 남는 문제가 있으면 격자 간격 또는 구조 보정 중 한 요소씩 비교 | 선택 정확도와 시간 변화를 각각 기록 |

1·2단계의 선택에는 예측 구조의 원자 거리와 MEGADOCK 점수만 사용한다. 결정 구조 기반 RMSD·접촉 회복률은 선택 이후 대조군 성능 평가에 사용한다. 최초 적용 범위는 현재 구조 평가 대상인 상위 100개다.

3단계에서 상세 출력의 내장 RMSD는 분리·회전된 입력 좌표를 기준으로 계산되므로, 프로젝트의 결정 구조 기반 RMSD와 구별해 해석한다. 점수 항별 분석에는 고정된 입력과 기존 회전 샘플을 사용한다.

Enhancer의 NanoBodyBuilder2 단독 예측과 RF3 복합체 경로는 이번 실행에서 확보한 조건을 기준으로 삼는다. 4단계에서는 이미 저장된 단독 예측 구조를 재사용해, 독립적인 도킹 선택 절차가 다른 대조군에서도 작동하는지 확인한다.

두 대조군에서 정답 구조를 사용하지 않는 선택 규칙을 평가한 뒤 새 후보 적용을 검토한다. Minimizer의 현재 도킹 입력은 결정 구조에서 분리한 단백질이므로, 새 서열의 접힘 오차까지 포함한 성능은 별도 확인이 필요하다. 형광 변화 평가는 구조 평가 이후 실험 데이터와 함께 진행한다.
