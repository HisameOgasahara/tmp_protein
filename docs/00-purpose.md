# 취지와 작업 순서

## 목적

AI 단백질 설계 파이프라인을 끝까지 직접 실행하고, 나오는 숫자의 의미를 공개 데이터로
교정하는 것.

`pae_interaction` 18이 나쁜 값인지 평범한 값인지 모르면 결정을 내릴 수 없음. 따라서 답이
알려진 사례로 채점기를 먼저 교정하고, 그 자로 새 설계를 측정하는 순서.

## 범위

| 다룸 | 다루지 않음 |
| --- | --- |
| 결합체 백본 생성, 서열 설계, 복합체 예측 | 단백질 합성·발현·정제 |
| 계산 지표 산출과 해석 | SPR/BLI 등 결합 측정 |
| 공개 데이터로 지표 임계값 교정 | 결합 친화도 예측 |
| 재현 실패의 원인 분리 | 임상·치료 적용 |

실험 수단 없음. 주장 가능한 최대치는 "실험으로 결합이 확인된 설계와 같은 필터를 통과".

## 단계별 성공 정의

| 단계 | 질문 | 계산으로 답 가능 | 기준 |
| --- | --- | --- | --- |
| ① 자기일관성 | 설계한 구조대로 접히는 서열인가 | 가능 | Cα RMSD < 2 Å |
| ② 복합체 채점 | 표적의 설계한 자리에 붙은 상태로 접히는가 | 가능 | `pae_interaction` < 10 |
| ③ 지표 교정 | ②의 기준이 알려진 정답을 가르는가 | 가능 | 공개 결합체가 ②를 통과 |
| ④ 실제 결합 | 붙는가 | **불가능** | 실험 측정 |

①과 ②를 섞으면 안 됨 — [03-design-run](03-design-run.md)에서 40개 중 ①만 통과한 설계가
21개.

## 작업 순서

각 단계가 다음 단계를 바꾼 경위는 [경과](history.md).

| # | 단계 | 상태 | 결과 |
| --- | --- | --- | --- |
| 1 | 채점기 교정 — 공개 TrkA_88이 ②를 통과하게 | 완료 | 1.496 Å / `pae` 5.86. 원인은 입력 준비의 표적 사이드체인 누락 ([기록](issues/2026-11-18-trka-target-sidechains.md)) |
| 2 | 임계값 확인 — 실험 라벨된 설계 채점 | 완료 | 비결합 14/14 통과, 결합 5/6 통과 ([02](02-filter-calibration.md)) |
| 3 | 설계 — 교정된 필터로 새 결합체 측정 | 완료 | 0/40. 대조군은 통과 ([03](03-design-run.md)) |
| 4 | 규모 확대 — 길이 고정으로 160개 | 완료 | 0/160. `pae` 최소 8.480, 통과율 95% 상한 1.85% ([04](04-scale-run.md)) |
| 5 | 집중 재추출 — 백본 1개 × 서열 50 | 완료 | **1/50 통과.** 한계 지점은 백본이 아니라 서열 수 ([05](05-focus-run.md)) |

2단계와 3단계를 합치면 — 필터는 선별 전 집단에서 거르고, 선별 후 집단에서는 가르지 못함.
2단계 집합 95개는 저자들이 이미 계산 필터를 통과시켜 실험에 보낸 것이고 그중 6개가 결합,
즉 통과 후 결합률 6/95 = 6.3%.

## 표적 선택 이유

TrkA. 공개 자료에 설계 구조·설계 서열·AF2 예측 구조·실험 결합 라벨이 모두 있어 채점기
교정이 가능한 유일한 조건. 출처는 [참고문서](references.md).
