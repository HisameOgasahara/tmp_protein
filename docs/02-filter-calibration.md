시드 0) · 방법: TrkA_88 재현에 쓴 것과 같은 AF2 initial guess 필터

## 결과

| 그룹 | 개수 | `pae_interaction` 중앙값 | 범위 | 필터 통과 |

| 실험에서 비결합 | 14 | 5.54 | 4.39 – 8.80 | **14 / 14** |

중앙값 차이 0.24. 결합체 점수가 비결합체 범위 안에 들어감.

```
결합  (6): 4.42  5.41  5.71  5.86  6.18                      26.39
```

최저 점수 4.39와 통과선에 가장 가까운 정상 점수 8.80이 모두 비결합체.

`plddt_binder`(85.8–95.6)와 `binder_aligned_rmsd`(0.398–0.889)도 두 그룹을 가르지 않음.

## 이 집합의 성질

공개 자료 `PUBLIC_RELEASE/README`:

> "The Experimentally tested designs include **all ordered designs** described in the manuscript"

95개는 저자들이 합성을 주문한 설계 전부 — 생성 후보 전체가 아니라 선별 후 집합.

선별에 이 지표가 쓰였다는 근거는 논문 본문:

> "We attribute one order of magnitude to RFdiffusion, and the second to
> **filtering with AF2**"

업스트림 저장소도 `pae_interaction`을 실험 예측력이 가장 높은 점수로 지목.

| 구간 | 측정 가능 여부 |
| --- | --- |
| 생성 직후 후보군 → 선별 | 이 집합으로는 측정 불가 |
| 선별 통과 집합 안의 순위 | 측정함. 변별력 없음 |

앞 칸은 [03-design-run](03-design-run.md)에서 직접 설계한 날것으로 측정 — 0/40.

몇 개를 생성해 95개를 골랐는지는 논문에서 찾지 못함. 아카이브의 `insilico_tested` 폴더에
TrkA 결합체가 없어(Motif scaffolding, TIM barrel, NTF2 등만 있음) 선별 전후 대조군을 이
자료로 구성할 수 없음.

## 사용 규칙

| 점수 | 처리 |
| --- | --- |
| `pae_interaction` > 10 | 탈락 |
| ≤ 10 | 통과. 통과 집합 내 순위는 매기지 않음 |

이 표적에서 통과 후 실제 결합률 **6/95 = 6.3%**.

통과 개수를 보고할 때 비결합체 14/14도 같은 기준을 통과했다는 사실을 함께 기재.

## 부수 확인 — 재현성

20개 중 19개가 저자들의 공개 AF2 구조를 0.157–1.942 Å로 재현(중앙값 0.415 Å). 길이
55–94잔기 전반에서 성립 — 표적 사이드체인 이식이 특정 설계에 맞춘 수정이 아님.

## 예외: design_23

실험에서 결합이 확인된 설계. 배치 20.30 Å, `pae_interaction` 26.39로 단독 실패. 공개 AF2
구조와도 20.77 Å 차이.

| 점검 | design_23 | design_88 (성공) |
| --- | --- | --- |
| 사슬 구성 | A 94잔기 / B 101잔기 | A 93잔기 / B 101잔기 |
| 표적 서열 일치 | 예 | 예 |
| 결합여 내부 끊김 | 없음 | 없음 |
| 계면 최단 중원자 거리 | 2.21 Å | 1.96 Å |
| 계면 접촉 (< 4 Å) | 48쌍 | 52쌍 |

입력 결함 없음 — 표적 사이드체인 문제와는 다른 원인. 결합여 자체 접힘은 0.580 Å로 정확,
배치만 어긋남(원래 TrkA_88 실패와 같은 양상).

원인 미규명. TrkA_88에 적용했던 진단(시드·recycle 변경, 입력 특징 비교)을 그대로 돌리면
좁힐 수 있음. AF2 10여 회.
